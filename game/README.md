# Каркас игры (трек B, хакатон Сбер «Создаем эмоции»)

Чистые HTML, CSS и JS, ноль зависимостей. Вес каркаса около 40 КБ при бюджете 5 МБ.
`game.js` и `data/content.json` пока содержат рабочий **шаблон**: свайп-карточки «пускаю / не пускаю» с объяснением ошибки. Тему и механику заменяем, остальные модули оставляем.

## Запуск на Android

1. Собрать песочницу: `github.com/vveidi/sber-hse-hackathon-2026-android`, Android Studio, JDK 21, конфигурация `app`.
2. В папке `game/` запустить сервер: `python3 tools/serve.py`
3. Открыть игру в песочнице, на стартовом экране вставить адрес:
   - **эмулятор:** `http://10.0.2.2:8000`
   - **телефон по Wi-Fi** (телефон и ноутбук в одной сети): `http://<IP ноутбука>:8000`, IP печатает `serve.py`
   - **телефон по USB** (надёжнее Wi-Fi): включить отладку по USB, выполнить
     `~/Library/Android/sdk/platform-tools/adb reverse tcp:8000 tcp:8000`, адрес `http://localhost:8000`
4. Лог событий в песочнице (кнопка справа сверху) показывает каждое сообщение и реакцию приложения.
5. Отладка страницы: в Chrome на ноутбуке открыть `chrome://inspect`.
6. Добавьте `?debug=1` к адресу, и события будут печататься прямо на экране игры.

Сервер отдаёт файлы без кэша, как WebView в приложении.

## Структура

| Файл | Зачем |
|---|---|
| `index.html` | три экрана (заставка, игра, итог), окно объяснения, canvas для эффектов |
| `css/style.css` | стиль «наклейки», палитра в переменных, безопасные зоны, только системные шрифты |
| `js/core.js` | пространство имён `G`, помощники, `G.config` |
| `js/bridge.js` | пять событий: `close`, `finish`, `completed` (один раз), `vibrate`, `share` |
| `js/audio.js` | звук синтезом, по умолчанию выключен, переключатель в углу |
| `js/content.js` | загрузка JSON, при любой проблеме берётся запасной набор |
| `js/input.js` | `drag` и `swipeCard` на Pointer Events |
| `js/loop.js` | цикл `requestAnimationFrame`, на скрытой вкладке стоит |
| `js/fx.js` | конфетти, `pop`, `shake` |
| `js/ui.js` | `explain()` (мягкая обратная связь на ошибку), `toast()` |
| `js/share.js` | рисует карточку на canvas, отправляет `SHARING_EVENT` |
| `js/screens.js` | переключение экранов с хуками `enter` и `leave` |
| `js/fallback.js` | запасной контент, если файл не загрузился |
| `js/game.js` | **шаблон механики**, заменяется |
| `data/content.json` | **контент игры**, меняется без релиза |
| `tools/serve.py` | сервер для телефона |
| `tools/check.py` | вес и запрещённые вещи из ТЗ |

## Как пользоваться каркасом

```js
G.bridge.vibrate();                       // лёгкий отклик (клик на правильное)
G.bridge.completed();                     // игра пройдена, один раз за открытие
G.bridge.share({ text, image });          // системное «поделиться»
G.audio.sfx('ok' | 'bad' | 'win' | 'tap');// играет только если ребёнок включил звук
G.fx.confetti({ count: 60 });
G.ui.explain({ title, text }).then(...);  // объясняем ошибку и даём попробовать снова
G.share.send(text, function (ctx, w, h) { /* рисуем карточку 720x960 */ });
G.content.load('data/x.json', fallback, validate);
```

## Перед сдачей

```
python3 tools/check.py
```

Скрипт считает вес и ищет запрещённое: внешние адреса, ссылки, iframe, `window.open`, браузерные вибрацию и шаринг, хранилище страницы, пути от корня, `?.` и `??`. Код возврата 1 означает ошибку.

## Ограничения ТЗ, которые легко нарушить

- Любой внешний адрес, шрифт, библиотека или аналитика — нельзя. Пути только относительные.
- `localStorage` и cookies очищаются при открытии и закрытии, прогресс между запусками не живёт.
- Вибрация и шаринг только через `G.bridge`.
- `COMPLETED_EVENT` один раз. `bridge.completed()` повторно ничего не отправит.
- Звук не включается сам. Тексты короткие. Ошибку объясняем, не ругаем. Сессия 3–5 минут.
- Без тёмных паттернов: нет обратного отсчёта, нет «ещё одна попытка за…».
- Старый WebView Android 8: пишем без `?.` и `??`.

## Открытые вопросы к организаторам

- Нужно ли слать `FINISH_EVENT` вместе с `COMPLETED_EVENT` на итоге? Сейчас шлём только `COMPLETED_EVENT`.
- Есть ли лимит на размер data URL картинки в `SHARING_EVENT`? Наша карточка около 160 КБ.
